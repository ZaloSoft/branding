# ZaloSoft™ Brand Guide

## Assets

### all purpose

General assets related to ZaloSoft™. Assets in this directory are originally exported from a [Figma Project](https://www.figma.com/design/gZvZrsqygoiLxM1RACVKBT/Brand-Guide?node-id=0-1&t=lRcbEWUlhf0CjXc1-1), where elements are named as `<type> <theme> <variant>` (ie. `wordmark light 1`).

### favicon

Favicon assets are created by transforming the relevant `all purpose` assets using a [favicon generator](https://realfavicongenerator.net).

### fonts

Custom fonts.
